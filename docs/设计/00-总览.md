# 漫剧工作台：设计总览

工作名 yanxiang，产品名另定。2026-10-27 定稿。

## 这是什么

面向新人的本机漫剧制作工作台。用户用一句话（之后也可以导入一部连载小说）起头，系统产出一集约 2 分钟的 3D 国漫仙侠漫剧。用户只在审核点看图、看片、挑选、说意见，不写提示词，不剪辑。

## 核心决定

1. **一集是验收单位。** 先从一句话做出一集 96–144 秒的成片，再做小说导入；世界观、季规划、多集连续性放到一集跑通之后。
2. **流程是代码，模型是函数。** 阶段顺序、能否进入下一步、何时花钱都由代码决定。每次模型调用不带工具、不进循环，输入由代码按上下文清单组装，输出有固定格式。对话助手只负责把用户的话变成对某个产物的修改操作。
3. **一次只写一件东西，上下文最小充分。** 一次调用只产出一张图的描述、一段视频的时间轴或一集剧本，只读这件东西需要的、已经定下的内容。先框架后细节放在层级之间：集 → 段 → 秒，人物 → 外观要点 → 定妆描述。
4. **出图满意就钉死，钉死的是图。** 模型对没给定的尺寸、长度每次写得不同，不靠事先列全来消除，而靠出图后由用户挑一张锁定。之后所有用到它的请求只绑这张图，不再带当初的提示词。
5. **所有图和视频都由人看；花钱前要用户点开始。** 程序只做能确定的检查，不用审查模型替人判图、选片；视觉模型只用来裁头尾。
6. **提示词是代码配置，画风和题材是插件。** 系统提示词和固定句是代码仓库里的配置文件；任务提示词只写通用内容，画风和题材的要求写在插件里，组装时插入。第一版只内置「3D 国漫」画风插件和「仙侠」题材插件，不提供选择，为以后扩展留好接口。
