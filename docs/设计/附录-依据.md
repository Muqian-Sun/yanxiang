## 一、manju 为什么一集都跑不出来

| 问题 | 证据 | 对应设计 |
|---|---|---|
| 旧经验脏，提示词冲突重复 | 旧项目规则和技能共 1,528,566 字节；写一条图片提示词前要读约 179 KB，视频约 147 KB，分镜关键帧约 297 KB。字数标准三套叠加：门禁要求不少于 350 词，官方文档说对白多时别硬凑，定参数用的那条真实提示词只有 162 词。腰以上、无参考图的发型测试被写成了全身照规则。一条已提交的关键帧提示词约 3194 字符，两段互相矛盾、场景物件写了两遍。真正有对照组的实测约 9 条 [核对] | 有用的经验经创作者逐条审定后写进提示词配置和流程设计（05）；审核过程稿归档 |
| 上下文太大 | 视觉、分镜子 agent 的上下文包中位约 6.0 万字，顶在代码上限 `BRIEF_LIMIT = 60_000` 上；设计师 agent 峰值输入中位 8.2 万 token、最高 42 万；单次 `ManjuGet` 最多取回 62.9 万字；9 个子 agent 共用 19 个工具；两部试跑合计读入约 2.47 亿 token、写出约 310 万 [核对] | 上下文清单写死在代码里，模型不带工具（02） |
| 提示词写不全 | 分镜单任务最多新建 73–79 条，一套造型约 200 个待填字符串；有省事实例（景别只剩名词、细节写「无。」），但定妆提示词中位仍有 5505–6158 字 [核对]。系统提示词要求的是「把字段填满」，不是「看得见的都写」[历史分析]。定妆照实验：最小上下文（每次约 5.3k token）单次只写一张，创作者判断写得详细；先列框架再逐元素写，读入约为单次写的 60 倍 [核对] | 一次只写一件；系统提示词点名要写详细的地方；出图后钉死（03） |
| 一上来做长篇 | 第 4、5、7、8、9 次试跑停在故事库阶段；但后来有日志的两部试跑里，83% 的输入 token、73% 的子 agent 时间花在第 1 集的视觉、分镜、资产和归因上，两部都没出视频 [核对] | 一集是验收单位；长篇和多集推到 M3、M4 |
| 单集生产循环转不动 | 工具调用 4853 次，出错 583 次（12%），约六成是参数不对；子 agent 常因中断、轮数用完、接口 429/503 没跑完；上游一改分镜整段过期 [核对] | 模型不带工具；失效只沿引用边传播 |
| 导演在当流程引擎 | 导演挂 20 个工具，既要理解用户又要派活、判断阶段、处理失败 [核对] | 流程由代码驱动，对话助手只出修改意见 |
| 生成链路硬缺陷 | manju 缺陷清单 A–J：状态矛盾写进提示词、上游改了不重做、重复扣费、审查放水 [核对] | 锁定版本和输入快照；拿不到任务号就停；不自动重出 |

## 二、旧项目实测（H3）

- 钉帧：文戏 15 秒三切，同一提示词两颗种子，不钉帧切点漂到 5.08–5.38 秒和 8.54–8.71 秒，钉帧后落在 5.00 和 9.00（`tianyanzhizhu/config/benchmarks/r3-structure-a.jsonl`）。
- 速度（5090，n=2）：关稀疏注意力约 340 秒，开约 165–178 秒；576p 比 768p 快一倍多；四步约 93 秒、八步约 165–184 秒、十四步约 258 秒；精修到 1080 约 396 秒。
- 承接：只给末帧、重放 22 帧、重放 39 帧三种只量了耗时（约 91–111 秒），接缝没有测量；创作者看片判断重放比首尾帧好得多。
- 未测：同种子复现、钉帧版精修、打戏和特效在钉帧下（`h3_profile.json` 113–114 行）。

## 三、同类产品与方法（2026-10 调研）

- 即梦、LTX Studio、Story.com 都把审核放在出视频之前来省钱。
- 小说改编的公开方法一致：按局势变化分集，不按章或字数均分，「一集对应多少原文」没有稳定公式（Dramily、ZenStory）；长摘要按章节树自底向上合并比平铺切块更连贯（ToM，EMNLP 2025）。
- 长任务写不全的公开研究：信息在长上下文中段效果变差（Lost in the Middle）；上下文变长本身就降低表现（Context Rot）；长输出会提前停或压缩（LIFEBench）。

## 四、小说入口的设计要点（M3）

- 流程：导入 → 程序按章切分 → 每章一次调用写摘要（只读这一章）→ 一次调用读全部摘要提议前若干集的分集卡 → 创作者确认 → 只展开当前集，剧本任务读这一集的分集卡和它覆盖的那几章原文。
- 分集卡写清：覆盖哪几章、本集核心事件、删了哪条支线、哪段内心独白改成了什么可见动作、结尾钩子。
- 摘要很长时先按卷合并再提议分集；第一版只提议前 10 集（拍的）。
