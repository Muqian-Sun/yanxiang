# 开源经验测试清单

日期：2026-10-27。调研见 [AI漫剧开源方案对比与改进建议](AI漫剧开源方案对比与改进建议.md)。实验数据都在 `~/Downloads/yanxiang-feat-story-craft/runs/ab-*`。

## 已测，采用

| 做法 | 来源 | 怎么测的 | 结果 |
|---|---|---|---|
| 剧本前先写本集设定（世界、规则、人物筹码、真相、地点、独有时刻） | Toonflow、zenstory、waoowaoo | 剧本盲审第一轮（`ab-story`） | 创作者判新版好 |
| 剧本先写正文、再拆成拍，环境段挂回场 | 火宝、ViMax、waoowaoo、Toonflow | 同上 | 同上 |
| 剧本写作规则：对手会换打法、不靠巧合救兵、台词在做事、写完自查 | waoowaoo、drama-skills、screenwriting-skills | 同上 | 同上 |
| 仙侠故事、台词片段，《凡人修仙传》口吻范例 | zenstory 仙侠卡、oh-story 东方仙侠卡、经验审核 05-30～05-35 | 同上 | 同上 |
| 本集设定限八百字、审读后改写、开场画外音、节奏底线 | Toonflow 审核、waoowaoo 自评与节奏档位、oh-story 套话表、经验审核 05-01 | 剧本盲审第二轮（`ab-script`） | 创作者判改进版好；设定从约 2200 字降到约 1000 字 |
| 审读加「常理」一类 | drama-skills 漫剧三问、经验审核 05-05 | 3 份剧本新旧各审一次（`ab-review`） | 两份里挑出原版没发现的真问题（膝坑、洞门自开、捡失效断钥） |
| 地点：身份、视觉中心、颜色主次、压人的主体、可见尺度、关门不写门外 | Toonflow、xianxia-visual-director | 改三轮各出图（`ab-story/images`） | 从灰矿洞变成有主体的禁地 |
| 人物、地点、道具加锚点；描写不再要求写全 | shuohao、drama-skills、waoowaoo | 新旧各出一轮图（`ab-assets`） | 定妆描写约 1600 字到约 1000 字，道具约 530 到约 300 字，出图质量相当 |
| 道具只收有特写、承载剧情的 | shuohao、火宝 | 同上 | 每组 6～7 件降到 3～5 件，门不再当道具 |
| 兵器法器按中式形制 | Toonflow 传统器物 | 同上 | 西式十字护手消失 |
| 分段的台词时长检查 | 火宝、Toonflow | 单元测试；历史 43 段；新剧本 3 次分段 | 历史无超标；新剧本触发 1 次并改正 |
| 长度不用米和厘米 | 实验里发现 | 统计 | 改后为 0 |
| 女角鞋按造型选：宗门服、劲装配过膝长靴 | 创作者要求 | 三组女主重新设计（`ab-assets/shoes`），出图 1 张（`ab-images/t-boots.png`） | 3/3 从高跟改为过膝长靴，图上是宗门长袍配过膝长靴 |
| 按戏的类型选写法（文戏、打戏、情绪段各用各的写法） | ViMax 意图路由 | 15 份剧本盲审（`ab-script4`），每条做法各 3 份 | 最好的 4 份里占 2 份；创作者确认采用 |
| 近景和特写占一半左右 | drama-skills 节奏档案 | M1 的 8 段：近景类 0% 到 59%；同一镜头新旧关键帧对比 | 创作者判明显更好；镜头和关键帧多约三成 |
| 画风按情境配光色 | Toonflow 国风三维 | 同一描述换画风句重出 | 创作者确认采用 |
| 外景：单一主光、一个风向、云海在脚下、留出空气 | xianxia-visual-director | 同一地点新旧各出图 | 创作者确认采用 |
| 衣物鞋靴不用拉链 | 统计时发现 1 处 | 规则已加，下次人物设计时核对 | 待核对 |

## 链路审查（2026-10-28）

新故事开工前对整条链路和全部系统提示词做的审查。改过的提示词都用之前的真实输入重跑过；程序改动都有测试，并做过负向验证。

| 改动 | 来源 | 核实 |
|---|---|---|
| 每个镜头至少 4 秒，景别变化在同一镜头里推拉摇完成 | 创作者要求 | 样片 8 段重写两轮：镜头 35 → 11，最短 4 秒，近景或特写 9～10 个（8 个靠推近） |
| 画面里有背影的人物用三视图，不用定妆照 | 创作者要求 | 时间轴标出背影（样片 2 段）；关键帧和视频都改绑三视图，端到端测试覆盖 |
| 镜头起止写「开始和结束的那一刻」，打回提示写清哪两个镜头没接上 | 4 秒规则后暴露：模型写 0–4、5–9 | 样片 8 段全部通过，打回最多 1 次 |
| 地点设计补上「本集设定里的世界和地点」「剧本里这个地点的环境」，道具写「名字：持有人」 | 和 `ab-story` 测过的输入对齐 | 单元测试逐段核对段名、顺序和内容 |
| 时间轴：冲突处以最近验证过的为准，只删掉「推近和定格只用在情绪爆发」里的「推近和」（近景用推近是 10-27 验证采用的）；其余照 10-28 02:07 验证过的原话（对白镜头顺序、高潮多角度重复、远近变化不切镜） | 提示词审查；创作者 10-28 纠正：4 秒只是下限，放不下就加时长 | 见下方复测 |
| 定妆描述清单去掉重复的外观年龄 | 提示词审查 | 3 份女主：第一句写明性别年龄，「岁」只出现一次 |
| 皮肤写「哑光的冷中性肤色」，去掉「无油光」 | 和「不写泛泛的否定」冲突 | — |
| 地点设计「只写开场」合成一处，长度单位统一为人体比较或丈、尺、掌、指 | 提示词审查 | 2 次重跑都没有米、厘米 |
| 分段：保留「一段可以跨场景」，加「每个镜头至少 4 秒，镜头放不下就加长这一段，15 秒还放不下就拆成承接的两段」；程序改成每个镜头可写自己的地点，机位分组、机位图、关键帧、视频参考都按镜头所在的地点取 | 创作者 10-28 纠正：换地点另起一段不对 | 单元测试和跨地点的流程测试；真模型复测见下方 |
| 审读：去掉重复的「二十字」，程序检查最多 10 条 | 提示词写了上限但程序没查（重跑时出过 15 条） | 单元测试 |
| 本集设定加「写这六项时记住」 | 提示词审查 | 新旧各 3 次：旧 1373～1500 字，新 1454～1660 字，没证明更好，已撤回 |
