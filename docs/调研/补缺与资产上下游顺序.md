# 补缺与资产上下游顺序

日期：2026-10-28。对照现行设计（[04](../设计/04-流程引擎.md)、[05](../设计/05-任务卡与提示词.md)、[06](../设计/06-出图.md)）、实现（`src/pipeline/entities.ts`）与经验审核（[提炼版](../归档/经验审核/提炼版.md)、[一句话/01](../归档/经验审核/一句话/01-人物外观.md)、[一句话/02](../归档/经验审核/一句话/02-场景与道具.md)），回答两件事：还要补什么；人物定妆、道具、衍生图之间的顺序要不要再细。

剧本与题材侧的缺口见 [开源方案对比与改进建议](AI漫剧开源方案对比与改进建议.md)；本文只管资产链路和与之咬合的上下游。

## 结论

1. **资产主链不用推倒重排。** `brief → desc → image → derive` 与「地点等场内道具」已经写在代码里，和实测一致。
2. **定妆与道具保持并行。** 不要加「人物定妆等道具锁完」；佩戴件只在 brief 里写位置，形制归道具，状态（出鞘、伤、湿）不进定妆。
3. **要补细的是派生边，不是主链。** 设计写了、代码未齐的：道具三视图；场景主图/关键帧应绑道具三视图；多造型作用域以后再加。
4. **产品上更急的仍是「戏」和题材。** 一致性工程先别动；本集设定、正文、仙侠 story/location 片段按改进建议做。

## 一、现行顺序（以代码为准）

```text
style_ref（画风插件自带）
  │
  ├─ char brief（同种内按 roster 顺序，后者看见前者）
  │     └─ desc → image（定妆照，无参考图）→ lock
  │           ├─ derive /三视图
  │           └─ derive /脸部特写
  │
  ├─ prop brief（同种内顺序同上）
  │     └─ desc → image（道具设定图）→ lock
  │           └─ （设计要求、代码未做）derive /三视图
  │
  └─ loc brief（等场内道具 brief；可读 setup）
        └─ desc → image（等 style_ref + brief 点名的场内道具 lock）→ lock
              └─ view / 关键帧（等人物、地点、道具参考图）
```

对应前置条件：

| 节点 | 已实现的前置 | 出处 |
|---|---|---|
| `brief`（人物/道具） | 本集 script、roster；同种更早实体的 brief | `entities.ts` |
| `brief`（地点） | 同上，外加场内道具 brief；有 setup 则读入 | 同上 |
| `desc` | 本实体 brief 已锁 | 同上 |
| `image`（人物/道具） | 本实体 desc 已锁 | 同上 |
| `image`（地点） | desc + `style_ref` + brief 里点名的场内道具 `entity_lock` | 同上 |
| `derive`（人物） | 该人物根图 `entity_lock` | 同上；产物为三视图、脸部特写 |
| `audition` | 人物根图锁 | `video.ts` |

设计 [04](../设计/04-流程引擎.md) 曾写「画风 → 人物 → 造型 → 关键道具 → 地点主图 → 关键帧」。其中「造型」在代码里还没有独立作用域；人物与道具的 image **互不等待**。下文「建议锁定顺序」以代码与经验为准，设计文档应改写成与之一致。

## 二、经验里已经钉死、不要改的规则

| 规则 | 含义 | 对顺序的含义 |
|---|---|---|
| 定妆不绑风格帧 | 风格帧里的发饰/服色会污染人物 | 定妆 `image` 参考图列表为空 |
| 持物状态不进定妆 | 刀在不在鞘里随剧情变 | 定妆 brief/desc 不写状态；变体走切点或状态图 |
| 人 / 造型 / 状态三层 | 脸体跟人；发型衣饰跟造型；伤湿出鞘跟状态 | 一张定妆只画一套能同时成立的状态 |
| 佩戴道具形制归道具 | 人物 brief 只写「戴在哪」 | **定妆不依赖道具图** |
| 场内关键道具进地点 | 身上的不进场景 | 仅 brief 点名的摆放件挡地点出图 |
| 三视图 / 脸特写绑定妆 | 从根图改，不互参 | `derive` 只等根 lock |
| 一组一个根 | 造型变体也以根定妆为底 | 变体是派生，不是第二条主链 |

## 三、设计写了、实现未齐（要补细的顺序）

| 缺口 | 设计 | 代码现状 | 建议 |
|---|---|---|---|
| 道具三视图 | [05](../设计/05-任务卡与提示词.md) / [06](../设计/06-出图.md)：场景主图、关键帧绑「关键道具三视图」 | `DERIVED` 只有人物；地点 `image` 只等道具**根图** lock | 道具根图锁后增加 `derive`（三视图）；地点与关键帧改绑三视图（无三视图前可暂绑根图，但要在审核台标明） |
| 人物 → 造型 | 04 锁定顺序含「造型」；经验要求换装单独锁一张定妆 | 一人一套，无 `costume` 作用域 | M1 继续一人一套；多造型时：`char` 身份锚点锁 → 每套 `costume` 自走 brief/desc/image，共用脸体 |
| 表情图 | 经验：表情绑三视图 | 无节点 | 按需：三视图锁 → 表情；不进主链硬门 |
| 共穿制服平铺 | 经验：无人服装平铺给龙套绑 | 无 | 按需节点；可先于龙套定妆，不挡主角 |
| 文档与代码 | 04「造型在道具前」 | 人物/道具并行 | **以本节建议图为准改 04** |

### 建议钉死的派生 DAG

```text
人物 brief → desc → 定妆照锁 ─┬─ 三视图锁 ─┬─（可选）表情
                              │            └─ 背影镜改绑三视图
                              ├─ 脸部特写
                              └─ 试音

道具 brief → desc → 设定图锁 ── 道具三视图锁 ──┐
                                                ├─ 地点主图
                                                │   （仅 brief 点名的场内件）
人物定妆 / 地点视图 / 道具三视图 / style_ref ──┴─ 关键帧 → 段视频
```

**明确不做的边：**

- 佩戴道具 lock ↛ 人物定妆前置
- 风格参考图 ↛ 人物定妆 / 道具设定图参考（只给场景主图、换机位、关键帧）
- 状态变体 ↛ 重锁根定妆（伤、湿、出鞘单独出图或写进切点正文）

## 四、还要补什么（按优先级）

一致性（锁图、越界词、数量写死、permit、stale）先不动。

### P0 — 和成片质量直接相关

| 项 | 做什么 | 依据 |
|---|---|---|
| 戏与题材 | 本集设定 → 正文 → 审读改写 → 拆拍；仙侠插件补 `story` / `dialogue` / `location` | [改进建议](AI漫剧开源方案对比与改进建议.md) |
| 地点上游 | 引擎 `loc brief` 读齐 setup「世界一角/地点」与各场环境段（M0 chain 已组装，实体节点对齐） | 改进建议第三节；设计 10 M2 |
| 道具三视图边 | `DERIVED` 扩到道具；地点 `image`、关键帧/视频选图改绑三视图 | 设计 05/06；经验 02-07 待定收口 |

### P1 — 资产模型补全（有多造型/多状态再做）

| 项 | 做什么 |
|---|---|
| 造型作用域 | `e1/char/沈照雪/造型/宗门服` 一类 scope；身份 brief 与造型 brief 分开 |
| 状态图 | 开场根图之外，损坏/出鞘等按需 derive 或切点描述 + 参考根图 |
| 制服平铺、表情 | 按需节点，审核仍在 ★5 |

### P2 — 工程对齐与文档

| 项 | 做什么 |
|---|---|
| 改设计 04 锁定顺序表述 | 改为与本文第三节一致 |
| 审核台 | 派生图等待态、参考图截断列表（已有设计）按新 DAG 展示 |
| 机械连续性检查 | 切点前后持物、造型、伤是否与状态表一致（经验有清单，引擎未做） |
