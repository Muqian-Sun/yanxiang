# 补缺与资产上下游顺序

日期：2026-10-28。对照现行设计（[04](../设计/04-流程引擎.md)、[05](../设计/05-任务卡与提示词.md)、[06](../设计/06-出图.md)）、实现（`src/pipeline/entities.ts`）与经验审核（[提炼版](../归档/经验审核/提炼版.md)、[一句话/01](../归档/经验审核/一句话/01-人物外观.md)、[一句话/02](../归档/经验审核/一句话/02-场景与道具.md)），回答两件事：还要补什么；人物定妆、道具、衍生图之间的顺序要不要再细。

剧本与题材侧的缺口见 [开源方案对比与改进建议](AI漫剧开源方案对比与改进建议.md)；本文只管资产链路和与之咬合的上下游。

## 结论

1. **资产主链不用推倒重排。** `brief → desc → image → derive` 与「地点等场内道具」已经写在代码里，和实测一致。
2. **定妆与道具保持并行。** 不要加「人物定妆等道具锁完」；佩戴件只在 brief 里写位置，形制归道具，状态（出鞘、伤、湿）不进定妆，手里拿的、会转手的道具也不进定妆，定妆双手空着。
3. **要补细的是派生边，不是主链。** 道具三视图不用另做：道具设定图本身就是正面、侧面、背面三视图加一处细节放大（`config/prompts/image-types/prop-sheet.md`），场景主图和关键帧已经绑它。还没做的是多造型和共穿制服的平铺图。
4. **产品上更急的仍是「戏」。** 改进建议里的做法（本集设定、先写正文再拆拍、审读改写、仙侠 story/dialogue/location/sample 片段、按戏的类型选写法）都已接入，并经三轮盲审判为好于旧版（[开源经验测试清单](开源经验测试清单.md)）；但创作者 2026-10-28 判断现在的戏剧效果仍然很差，要另开任务，从最近的剧本逐场诊断。

## 一、现行顺序（以代码为准）

```text
style_ref（画风插件自带）
  │
  ├─ char brief（同种内按 roster 顺序，后者看见前者）
  │     └─ desc → image（定妆照，无参考图）→ lock
  │           ├─ derive /三视图
  │           └─ derive /脸部特写
  │
  ├─ prop brief（同种内顺序同上）
  │     └─ desc → image（道具设定图：正面、侧面、背面三视图）→ lock
  │
  └─ loc brief（等场内道具 brief；可读 setup）
        └─ desc → image（等 style_ref + brief 点名的场内道具 lock）→ lock
              └─ view / 关键帧（等人物、地点、道具参考图）
```

对应前置条件：

| 节点 | 已实现的前置 | 出处 |
|---|---|---|
| `brief`（人物/道具） | 本集 script、roster；同种更早实体的 brief | `entities.ts` |
| `brief`（地点） | 同上，外加场内道具 brief；有 setup 则读入 | 同上 |
| `desc` | 本实体 brief 已锁 | 同上 |
| `image`（人物/道具） | 本实体 desc 已锁 | 同上 |
| `image`（地点） | desc + `style_ref` + brief 里点名的场内道具 `entity_lock` | 同上 |
| `derive`（人物） | 该人物根图 `entity_lock` | 同上；产物为三视图、脸部特写 |
| `audition` | 人物根图锁 + 人物 brief 锁；只给有台词的人物建 | `video.ts` |

设计 [04](../设计/04-流程引擎.md) 曾写「画风 → 人物 → 造型 → 关键道具 → 地点主图 → 关键帧」。其中「造型」在代码里还没有独立作用域；人物与道具的 image **互不等待**。04 的锁定顺序已按代码与经验改写。

## 二、经验里已经钉死、不要改的规则

经验审核 [01-19](../归档/经验审核/01-人物外观.md) 定了「拿着、挂着的东西记在那件东西身上」，但原先的人物设计提示词只排除了伤、湿、出鞘这类状态，手里拿的道具没覆盖，还把 roster 里道具的转手经过（`holder`）原样交给模型、要它「照持有方式写」。实测：「废脉一开」一集里，沈照雪的 brief 写出「婚书由手中持握」，定妆照画成双手捧着婚书；萧烬的 brief 把剧终才收进怀里的婚书一角写成胸前暗袋。本次已改：`character-design` 只拿到道具名、不拿转手经过，规定手里拿的、会转手或会用掉的不进造型；`portrait-desc` 和出图固定部分 `portrait.md` 补「双手空着」。已锁的 brief 不会自动重跑，要在审核台带意见重做。

| 规则 | 含义 | 对顺序的含义 |
|---|---|---|
| 定妆不绑风格帧 | 风格帧里的发饰/服色会污染人物 | 定妆 `image` 参考图列表为空 |
| 持物状态不进定妆 | 刀在不在鞘里随剧情变 | 定妆 brief/desc 不写状态；变化写进切点正文 |
| 手持道具不进定妆 | 拿在手里、会转手或用掉的东西随剧情变 | 定妆双手空着；拿着什么由关键帧写 |
| 人 / 造型 / 状态三层 | 脸体跟人；发型衣饰跟造型；伤湿出鞘跟状态 | 一张定妆只画一套能同时成立的状态 |
| 佩戴道具形制归道具 | 人物 brief 只写「戴在哪」 | **定妆不依赖道具图** |
| 场内关键道具进地点 | 身上的不进场景 | 仅 brief 点名的摆放件挡地点出图 |
| 三视图 / 脸特写绑定妆 | 从根图改，不互参 | `derive` 只等根 lock |
| 一组一个根 | 造型变体也以根定妆为底 | 变体是派生，不是第二条主链 |

## 三、设计写了、实现未齐（要补细的顺序）

| 缺口 | 设计 | 代码现状 | 建议 |
|---|---|---|---|
| 人物 → 造型 | 04 锁定顺序含「造型」；经验要求换装单独锁一张定妆 | 一人一套，无 `costume` 作用域 | M1 继续一人一套；多造型时：`char` 身份锚点锁 → 每套 `costume` 自走 brief/desc/image，共用脸体 |
| 共穿制服平铺 | 经验：无人服装平铺给龙套绑 | 无 | 按需节点；可先于龙套定妆，不挡主角 |

已经补上或决定不做的：

| 项 | 结果 |
|---|---|
| 道具三视图 | 道具设定图就是三视图，不另做派生 |
| 人物自带物件与道具同名 | 已做。实测萧烬的 brief 自加一块「腰牌」并写进锚点，而道具「腰牌」属于赵衡、剧中会炸裂；视频提示词会把每处「腰牌」都绑到赵衡那件的设定图。人物设计现在拿到「本集其他人的道具」，输出里出现这些名字就打回重写 |
| 表情图 | 不做：链路里没有用它的地方，看清五官已有脸部特写（创作者 2026-10-28） |
| 状态图 | 不做：道具和人物变化后的样子继续写进关键帧描述和视频提示词（创作者 2026-10-28） |

### 建议钉死的派生 DAG

```text
人物 brief → desc → 定妆照锁 ─┬─ 三视图锁 ── 背影镜绑三视图
                              ├─ 脸部特写
                              └─ 试音

道具 brief → desc → 设定图（三视图）锁 ──┐
                                          ├─ 地点主图
                                          │   （仅 brief 点名的场内件）
人物定妆 / 地点视图 / 道具设定图 / style_ref ──┴─ 关键帧 → 段视频
```

**明确不做的边：**

- 佩戴道具 lock ↛ 人物定妆前置
- 风格参考图 ↛ 人物定妆 / 道具设定图参考（只给场景主图、换机位、关键帧）
- 状态变体 ↛ 重锁根定妆（伤、湿、出鞘写进切点正文）
