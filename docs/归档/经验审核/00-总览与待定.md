## 三、设计待定项

这几项不是审某条旧经验，而是审核时发现设计文档本身没答到，或者和实测冲突。定了之后我更新设计文档。

### 待定 1：「只绑图」要不要留一个窄例外 —— 已定

**你的决定（2026-10-27）**：要。允许极短区分词（陈设写数量、多人同框人名后加主色），场景图里出现关键道具时绑它的三视图；锁定顺序随之调整为关键道具先于地点主图。已写进设计文档 6.3 和 `规则/经验规则.md`。

**问题**：设计定的是锁定后只绑图、不带当初的提示词。旧项目有两个实测漏洞：

- 只绑场景主图、不写陈设时，长老座从 5 把变成 3 把，鉴品石变矮（[02-02](02-场景与道具.md)）。
- 关键帧里不在人名后写服装时，苏晚棠穿上了顾言的衣服（[03-05](03-画风与图片写法.md)）。

另外，锁定图只管它画到的部分：背面、被挡住的地方、没露出来的鞋和腿都管不住（[01-06](01-人物外观.md)）。

**选项**：

- [ ] A（建议）：允许写极短的区分词，不写完整描述，也不抄当初的提示词。数量写「五把长老座」；多人同框时人名后加主色，如「穿白袍的沈照雪」。定妆照要求全身、露出鞋，并从它派生背面、侧面、脸部特写一起锁定。
- [ ] B：严格只绑图，问题靠你看图时发现再重出。
- [ ] 其他：＿＿＿＿

区分词的写法（几个字、写什么）是拍的，M1 实测后再定。

**你的疑问（2026-10-27）**：会不会是场景主图里没有椅子，同时也没绑石头这些关键道具的三视图导致的？

**核查**（旧项目 `.cursor/skills/short-drama-image-prompts/references/业界做法/通用/场景设定图.md` 第 18–28 行）：

- 主图里有长老座：测试记录写「台阶、测品台、鉴品石、主位与长老座、大殿、远山都在」。座位数是在换了机位的第二张图上变的，两侧各约 5 把变成 3 把。
- 关键道具的三视图确实没绑：第二机位只绑了主图和平面图，提示词只抄了背景句，没写陈设的数量和形制。
- 第二轮每条提示词都写了陈设的形制和数量（如「石凳每侧三条」），反打板和主图一致；没写时画成六排薄长凳。
- 所以更像是换角度后模型按自己的理解重画了陈设。绑关键道具三视图应该有帮助，但旧项目没测过这种做法。

**新选项**：

- [ ] A：允许写极短的区分词（数量、主色），同时绑关键道具的三视图
- [ ] B：只绑图，但要求主图画全所有陈设、关键道具都绑三视图；M1 对比「加数量短句」和「不加」两种
- [ ] C：严格只绑图，靠你看图时发现再重出
- [ ] 其他：＿＿＿＿

### 待定 2：哪些段之间要承接 —— 已定

**你的决定（2026-10-27）**：「一个一个出不就行了吗」。按顺序一段一段出，上一段采用后才出下一段，下一段接已采用的那条尾巴。整集草稿拼好后要重做中间某段，接在它后面的段按顺序重出。已写进设计文档 6.5。

**问题**：重放上一段末尾 22 帧时，后一段依赖前一段。中间某段重做，后面接着它的段都要跟着重出，「只重做那一段」就不成立了。另外还没定：承接用草稿的尾巴还是精修的尾巴（[06-05](06-分镜与剪辑.md)）；一段能不能跨场景（[06-02](06-分镜与剪辑.md)）。

**选项**：

- [ ] A（建议）：只在同一个连续动作被 15 秒截断时承接，其余段之间直接切（这也是旧规矩）。这样重做一段最多牵连它后面紧接的那一段。一段不跨场景。草稿之间用草稿尾巴承接；精修时用前一段精修后的尾巴，M1 对比两种接缝。
- [ ] B：同一地点内的段都承接，重做时后面的段跟着重出。
- [ ] 其他：＿＿＿＿

### 待定 3：谁来裁每段的废头废尾 —— 已定

**你的决定（2026-10-27）**：「我审完，模型切」。你采用一段后，视觉模型给出入点出点，程序裁；模型只决定裁哪里，不决定用不用。已写进设计文档 6.6。

**问题**：H3 生成的段开头常有 0.3–0.8 秒发呆或形变，结尾动作做完后空转、嘴还在动（[06-23](06-分镜与剪辑.md)）。旧做法靠审查模型标可用区间，新系统不用模型判片。设计里只写了「剪掉开头的重放部分」。

**选项**：

- [ ] A（建议）：你在看段草稿（★6）时拖一下入点和出点，程序先给一个默认值（默认裁多少是拍的，M1 看片后定）。
- [ ] B：程序按固定时长裁，你不管。
- [ ] C：不裁，分段时每段多留余量。
- [ ] 其他：＿＿＿＿

### 待定 4：闪白、顿帧、冲击帧、J/L 切这类剪辑手法 —— 已定

**你的决定（2026-10-27）**：B，写进段时间轴，让 H3 在段内生成。已写进设计文档 6.5。

**问题**：旧经验都放在剪辑里做，新系统的自动剪辑只拼接、加字幕、统一响度，这些没人做（[06-25](06-分镜与剪辑.md)，以及 06-26 转场、06-27 快切）。

**选项**：

- [ ] A（建议）：第一版不做，跑通一集后再加。
- [ ] B：写进段时间轴，让 H3 在段内直接生成。
- [ ] C：程序在剪辑时按规则自动加。
- [ ] 其他：＿＿＿＿
