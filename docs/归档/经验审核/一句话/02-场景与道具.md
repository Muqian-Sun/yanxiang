# 02 场景与道具（一句话版）

怎么填：在每条的「→」后面写 `留`、`删`，或 `改：你的说法`。不填的按初判处理。详细原文见 [../02-场景与道具.md](../02-场景与道具.md)。

## 要你审的（43 条）

- **02-06** 先把空间写合理：陈设撑得起剧情动作，人有路可走，东西之间不互相挡住。〔你的原话〕 初判：留 →
- **02-01** 固定陈设要写形制、数量和排法，只写类名时每张图都会重新设计一遍。〔实测〕 初判：留 →
- **02-04** 状态写成看得见的样子：断在哪、断口什么样、剩多少、怎么垂着，断口要写得显眼。〔只测过一次〕 初判：留 →
- **02-05** 主图和三视图画开场的样子，会变的东西不混进一直不变的描述里。〔只测过一次〕 初判：留 →
- **02-13** 主图要把整个地方和每件固定陈设都框进画面。〔实测〕 初判：留 →
- **02-12** 场景主图不画人，描述里本来有人群的，出图时改成空地。〔实测〕 初判：留 →
- **02-08** 换机位的场景图写清相机站在哪、站在哪一层、朝哪看、身后是什么。〔实测〕 初判：留 →
- **02-09** 反打写明哪些地标在相机身后、不入画；主图只借材质和陈设样式，不照抄构图。〔实测〕 初判：留 →
- **02-30** 镜头会用到的每个方向各锁一张场景图，同一方向只是景别不同就共用一张。〔实测〕 初判：留 →
- **02-21** 每处细节写清形状、大小、材质、颜色、在哪，看得见的都写，不写氛围和动态。〔你的原话〕 初判：留 →
- **02-22** 不往东西上加露珠、浮尘、清晨的静这类氛围修饰，会改掉它本身的物理状态。〔实测〕 初判：留 →
- **02-15** 刻字逐项写：横排还是竖排、几列、从哪列读起、每列原文、在哪一面哪里、多大，只出现一次。〔实测〕 初判：留 →
- **02-16** 被盖住的字只写露出来的字和「几个字被什么盖住」，不写被盖的是什么字。〔你的原话〕 初判：留 →
- **02-17** 古代刻字要有手写感：写书体、谁刻的、字有大有小、笔画深浅不匀、列与列错落。〔你的原话〕 初判：留 →
- **02-14** 道具三视图写明是给建模看的设定稿：正侧背同比例正交、平光、浅灰底、一处细节放大、无字比例尺。〔实测〕 初判：改 →
- **02-24** 正面写出这一件区别于同类物的一两处结构（如钥齿形状），光靠排除同类物不够。〔实测〕 初判：留 →
- **02-11** 数量和排法用只有一种读法的说法，如「过道两侧各三条，前后一条接一条错开」。〔只测过一次〕 初判：改 →
- **02-10** 其他方向的场景图锁定前，拿主图逐项数陈设几件、什么形制、地面纹样、关键道具多高，核是不是同一个。〔实测〕 初判：改 →
- **02-32** 位置只用画面方向和看得见的参照来写，不写东南西北，不写坐标。〔实测〕 初判：留 →
- **02-31** 场景图的背景从近写到远，只写这个方向固定不变的东西，不写人、动作、时段光。〔无证据〕 初判：留 →
- **02-35** 同一地点换时段、换天气，绑锁定的主图，只改光和天气，布局不动。〔只测过一次〕 初判：留 →
- **02-33** 暗场写唯一的暖色光源和保留色相的冷色阴影，不只写一个「暗」。〔外部文档〕 初判：留 →
- **02-34** 同一场的各个方向用同一个光源、同样的冷暖主次，改光就所有方向一起改。〔外部文档〕 初判：改 →
- **02-27、02-41** 不擅自给场景和道具加剧本里没有的东西：特效、雾、霓虹、逆光、多出来的门窗。〔你的原话〕 初判：留 →
- **02-26** 大人物的座驾和标志道具按主人身份阵营写足顶、柱、帘、底座、纹样、配色，不写最省事的形制。〔你的原话〕 初判：留 →
- **02-25** 法器按实物的材质和纹样设计，平时不发光，发光只写在发动的那一镜。〔实测〕 初判：留 →
- **02-28** 一张道具图只画一个状态，要用的状态绑完好那张锁定图单独出。〔外部文档〕 初判：留 →
- **02-40** 场景里的画像、雕像绑人物锁定图，并写明她只在画里，不是站在场景里的人。〔只测过一次〕 初判：留 →
- **02-42** 一件东西只在一处写全：剧情要用的石碑、锁链只作为道具写，地点里只说它在哪。〔你的原话〕 初判：留 →
- **02-37** 地点的外面单独写一条：在更大的地方的哪一处、外观、四周、门窗外和画框外紧挨着什么。〔你的原话〕 初判：改 →
- **02-38** 地点写清有多大（和人比）、有没有高差，以及地面、四周、头顶、植被、地上散落的东西。〔无证据〕 初判：改 →
- **02-36** 外景写月亮等天上看得见的东西在画面哪一侧，反打时换到对应的一侧。〔只测过一次〕 初判：改 →
- **02-23** 道具尺寸用人体作参照写（巴掌长、一人高、比站着的人高一头半），不只写「巨大」「小巧」。〔外部文档〕 初判：留 →
- **02-29** 两件要吻合的道具，吻合处写成对方的外形和大小，插进去以后的样子作为单独一个状态写。〔无证据〕 初判：改 →
- **02-39** 场景道具的材质写成略简化的手绘感、细纹理少，地面干燥哑光；放画风层，不进每个场景。〔实测〕 初判：改 →
- **02-43** 有字的东西先定观众要不要读到：要读的逐字写，不读的写成认不出的字样；现实品牌名由你定。〔外部文档〕 初判：改 →
- **02-20** 古代刻字带不带标点，请你定一次，写进口味层（旧资料互相矛盾）。〔无证据〕 初判：改（等你定） →
- **02-48** 剧情要「碎一道」「亮一道」的东西，写清一道长什么样、有几道、怎么排，数得出来。〔只测过一次〕 初判：改 →
- **02-47** 反复出现的特效定一句固定规格：颜色、形态、贴不贴着、往哪流、怎么散。〔无证据〕 初判：改 →
- **02-51** 有用途的关键道具写清发动时画面上看得见什么、用完变成什么样。〔外部文档〕 初判：改 →
- **02-45** 只给会被拿、被读、会变、会转手的叙事道具单独出图，背景里的东西留在场景里。〔外部文档〕 初判：留 →
- **02-50** 改编时，原著里不合理、画面里又难控制的陈设和细节可以删。〔你的原话〕 初判：留 →
- **02-49** 「旧、老式、斑驳」要有原著依据，旧只写在那件东西上，不把整个地点画旧。〔外部文档〕 初判：留 →

## 建议删的（1 条）

## 已定或另议（不用再审，5 条）

- **02-03** 东西的状态一变（锁链断、门开、青苔落），这一镜必须写出来。（你已定）
- **02-18、02-19** 古物年头写裂纹在哪、缺哪个角、边缘磨圆、苔痕、笔画不匀，不写毫米深度和坑洞密度。（你已定）
- **02-44** 不写泛泛的否定词，只对此刻确实不该出现的具体东西写否定，如「身后的牌坊不入画」。（你已定）
- **02-02** 陈设、背景、光的原描述不再逐字抄进下游；要不要补「五把长老座」这类极短区分词另定。（见待定 1）
- **02-07** 场景图画到关键道具时绑它的锁定图、只画一件；要不要绑关键道具三视图另定。（见待定 1）
