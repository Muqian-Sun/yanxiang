# 06 分镜与剪辑（一句话版）

怎么填：在每条的「→」后面写 `留`、`删`，或 `改：你的说法`。不填的按初判处理。详细原文见 [../06-分镜与剪辑.md](../06-分镜与剪辑.md)。

## 要你审的（45 条）

- **06-01** 一段完整打斗可以就是一个镜头、里面很多动作，不按「一个动作一个镜头」拆。〔你的原话〕 初判：留 →
- **06-10** 一段里要观众看清几件事按秒数分配，塞多了模型不删、会压扁；每件几秒在 H3 上测了再定。〔Seedance实测〕 初判：改写 →
- **06-03** H3 一段只收 4–15 的整数秒；短于 4 秒的镜头只能并进一段，镜头太多就并镜或拆段。〔外部文档〕 初判：留 →
- **06-08** 镜长从动作和台词推、不按字数折算；台词按每秒约 4 字留够时长，不让人物加速塞词。〔实测〕 初判：留 →
- **06-37** 段时间轴写到换个人只看字段也能画出同一个，肉眼看得出的都要写、要控制。〔你的原话〕 初判：留 →
- **06-16** 每场一张站位表，每镜的左右和朝向从表里推，不凭「这一镜好看」写。〔实测〕 初判：留 →
- **06-20** 切点前后对照站位表核位置朝向、持物、伤和造型、门灯天气；交接写成一条动作链；被打飞撞上的东西放在飞出那侧。〔实测〕 初判：留 →
- **06-12** 切镜要带来可见变化，景别、角度、人物关系至少变一项；同一视图不连用，只改远近或角度时用运镜不切。〔外部文档〕 初判：留 →
- **06-14** 说话时画里别人的正脸会抢口型，不说话的人出画或背身；画外音、内心独白时人物闭嘴。〔无证据〕 初判：改写 →
- **06-15** 不说话的人也要有反应和小动作，每个镜头至少两处不是静止，但小动作不改变这场戏的走向。〔你的原话〕 初判：留 →
- **06-13** 对白场先给关系镜头再过肩，单人特写留到情绪顶点，最重一句后切给听的人，不每句拆单人镜。〔实测〕 初判：留 →
- **06-09** 一句台词不跨段，段与段的接点不落在字音中间。〔无证据〕 初判：留 →
- **06-18** 一场锁一条轴线，画左往画右读作前往；换边只用镜内绕过、中性镜头、人走过去或回远景重建。〔外部文档〕 初判：留 →
- **06-17** 过右肩拍前景人在画左、过左肩在画右，正反打视线方向互补；对手在画外时写明他在哪条画框边外。〔实测〕 初判：留 →
- **06-19** 方向只写画面方向、不写东南西北；裸写的左右一律指画面左右。〔实测〕 初判：改写 →
- **06-32** 远景、全景不靠脸认人，写剪影、服色、站位；要认脸、要读字的那一拍推到中景以内。〔实测〕 初判：留 →
- **06-33** 规模感靠纵深和前排大脸；远处群像只做小幅错开的动作，要看个人反应就切近；空座椅写明无人。〔实测〕 初判：留 →
- **06-11** 推、撞类动作在接触点设切点钉关键帧，前半到接触为止、后半从接触后状态起；掌掴类可以一口气写全。〔实测〕 初判：改写 →
- **06-21** 同一个动作只演一次，下一镜接动作的后半；只有峰值的冲击可以多角度重复，并要写明。〔无证据〕 初判：留 →
- **06-29** 第一镜就是看得懂的钩子，开场全景带人物和动作；旁白讲规则时画面演在人身上；地理在动作里交代，不先给空景。〔你的原话〕 初判：留 →
- **06-02** 一段可以跨场，换场处钉关键帧、转场写进段时间轴；平行交叉的两条线分段写，不塞进同一段。〔无证据〕 初判：改写 →
- **06-27** 快切在段时间轴里写成一串越来越短的镜头；一段里切几刀角色还稳没测过，M1 先测上限。〔无证据〕 初判：改写 →
- **06-25** 时间轴里写闪白、顿帧时每个约 2–4 帧，全集各至多一处，只打在命中或揭示上，不落在对白中间。〔外部文档〕 初判：改写 →
- **06-26** 段内默认硬切；叠化只用在跨时间、约 0.3 秒；不用随机转场、故障、翻页这类掩盖手法。〔外部文档〕 初判：改写 →
- **06-31** 一镜一个主运镜、慢推最稳；不大幅摇镜、环绕不超过 90°，这几条在 H3 上待核。〔外部文档〕 初判：改写 →
- **06-30** 每镜写清运镜行为、起止和理由，固定也写理由；推近、定格这类强调只留给情绪爆发和反转。〔无证据〕 初判：改写 →
- **06-07** 一集镜长按自然长度排、不压缩；超目标两成以上把末尾挪到下一集开头，切点只落在两段之间。〔你的原话〕 初判：留 →
- **06-28** 段越长，一处出错要重做的越多，分段时把这个代价算进段长取舍。〔常识〕 初判：改写 →
- **06-36** 剧本每一拍都要有镜头承载；只引用画外人物的动作，等于这个动作没人拍。〔无证据〕 初判：留 →
- **06-34** 一场先开宽一档，第二镜落到本场的工作景别；镜长、近景占比等数字第一集看片后再定。〔无证据〕 初判：改写 →
- **06-35** 权力靠机位高低成对表达、反转时对调，不靠左右换位；水平角度、机位高度、焦段分开写。〔常识〕 初判：改写 →
- **06-40** 碑文、门匾这类画面字由 H3 在画面里生成，剪辑只叠台词字幕。〔无证据〕 初判：改写 →
- **06-39** 字幕烧进画面，按短剧惯例去句末标点、留问号叹号；构图时嘴、手和关键字避开底部约十分之一。〔外部文档〕 初判：改写 →
- **06-38** 字幕逐字照抄台词原文、标点也照抄，语音识别只定时间；起止落在发声区间，重做一段后重测。〔无证据〕 初判：留 →
- **06-43** 你看片时闭眼听接缝底噪跳不跳、看同场切点闪不闪；要不要自动校色第一集后再定。〔无证据〕 初判：改写 →
- **06-46** 看片核「是不是同一个」而不是「有没有」：陈设对母版、站位对站位表；原则错误必须改，小问题不改。〔你的原话〕 初判：改写 →
- **06-50** 你看出几次之间不一样的地方，就是字段没写住，补成唯一看得见的样子、只改管它的字段。〔你的原话〕 初判：改写 →
- **06-47** 指出问题写清哪一秒、画面上是什么、要保留什么；「不够电影感」「AI 味重」不算问题。〔无证据〕 初判：留 →
- **06-48** 归因先看那一次实际用的提示词和参考图，分提示词、参考图、缺数据、随机四类；视频出错先查参考图。〔无证据〕 初判：留 →
- **06-49** 判为随机就换种子原样重出、不改已对的正文；原样重投不超过两次；一次只改一个原因，不靠加形容词。〔实测〕 初判：留 →
- **06-51** 指出一处问题后，列出同一原因还影响的其他段交你决定，不自动重做。〔实测〕 初判：改写 →
- **06-53** 看成片：静音看一遍看得懂冲突，闭眼听一遍听得出换场，前 15 秒有第一记回报，抽三处切点看手脸持物。〔外部文档〕 初判：留 →
- **06-54** 判分镜手法看连起来的片子不看单张；出 576p 前要不要先拼关键帧小样你定。〔实测〕 初判：改写 →
- **06-44** 成片程序验收规格、总时长、字幕时间、黑场和静音，阈值第一集后按实测校准，声明过的静场豁免。〔无证据〕 初判：留 →
- **06-45** 每集开头右上角烧「AI生成」2 秒、字高不低于短边 5%，写隐式 AIGC 元数据；画面里不烧节目编号。〔外部文档〕 初判：留 →

## 建议删的（3 条）

- **06-55** 默认只出首帧、终点写进分镜，不用首尾帧模式。理由：新系统切点钉关键帧、段间靠重放承接，不用尾帧，实测也只在 Seedance 上。 →
- **06-56** 剪辑能删镜、缩镜、换顺序，删短后不机械补时长。理由：剪辑按段顺序自动拼接，没有取舍权。 →
- **06-57** 静帧镜头只在你选了时出现，不因省钱或失败自己换成静帧。理由：全片都是 H3 视频，坏段只重做，没有静帧顶上的入口。 →
