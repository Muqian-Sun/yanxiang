# 03 画风与图片写法（一句话版）

怎么填：在每条的「→」后面写 `留`、`删`，或 `改：你的说法`。不填的按初判处理。详细原文见 [../03-画风与图片写法.md](../03-画风与图片写法.md)。

## 要你审的（44 条）

- **03-01** 第一句先定性：镜头图写「中国 3D 动画剧集里的一帧」，设定图写「给建模用的设定稿」，人物放进场景里。〔实测〕 初判：留 →
- **03-08** 所有人物用同一档美型画风：理想化、精致、皮肤光滑无毛孔、眼睛细节清楚；凶和老只写在神态上，不写皱纹粗犷。〔实测〕 初判：留 →
- **03-09** 画风定在高清、皮肤光滑的精致 3D 国漫美型，介于真人实拍和平涂卡通、Q 版大眼之间，两头都不要。〔你的原话〕 初判：留 →
- **03-11** 参考图里有的东西都会被带进来，所以锁定图一图一人、一图一物；不得不共用合照时各写一个对方没有的标志。〔实测〕 初判：留 →
- **03-10** 每张参考图只管一件事，正文按编号写清「图 1 只取……，不取……」。〔外部文档〕 初判：留 →
- **03-06** 此刻在场、这个机位看得到的人全写进画面，远处小人和身后的人也要写；空座位写「空着」。〔实测〕 初判：留 →
- **03-21** 定妆、场景、道具图写到只看文字就能画出同一个：每样写形状、大小、数量、材质颜色、位置、朝向、此刻状态。〔实测〕 初判：留 →
- **03-28** 画风靠描述句，不靠作品名；不写画风默认偏明亮美型，要暗沉必须写调色；写实和美型只在色调、天气、光上分得开。〔实测〕 初判：留 →
- **03-27** 画风样张取这几样译成中文：美型脸、无毛孔哑光皮肤、成束发丝、略简化的手绘材质、柔和绘画式明暗、清楚纵深。〔英文版实测〕 初判：改写后留 →
- **03-03、03-31、03-32** 3D 国漫不写焦段、景深、虚化、布光光比、影棚和商品拍法；改写透视强弱、前中后景层次，主体靠造型和更亮的光分出来。〔只测过资产图〕 初判：留 →
- **03-23** 男女主必须帅、美，用具体的美型五官写出来，不靠「绝美」「英俊」这类形容词撑。〔你的原话〕 初判：改写后留 →
- **03-13** 方向只写画左、画右、前景、后景、朝向或背对镜头，不写东南西北，光向也一样。〔实测〕 初判：留 →
- **03-18** 只绑和本镜同一朝向的场景图，绑反了背景整个画反；室内图多对着出口画，背对出口的镜头不绑它。〔实测〕 初判：留 →
- **03-19** 近景绑场景图会被拉宽：先写具体取景，仍偏宽就这一镜不绑场景图；要认脸的推近镜也不绑。〔实测〕 初判：留 →
- **03-12** 关键帧只冻结起点那一瞬：终点才有的东西不写，动作只写到这一刻的姿势，判据是一张照片能否同时拍下。〔实测〕 初判：留 →
- **03-14** 每个在场的人写清在画面哪里、离镜头多远、身体朝向、看向哪、姿势、哪只手拿什么；关键人物再写离人群多远。〔实测〕 初判：留 →
- **03-48、03-49** 改图（含从定稿首帧改尾帧）写「只改某处」，逐项列出不变的，加「不要重新设计角色」；从定稿原图改，不在改过的图上接着改。〔实测〕 初判：留 →
- **03-20** 风格帧只给场景图和关键帧绑，写明只取渲染风格、材质处理、光的质感，不取人物、服装、场景、特效。〔实测〕 初判：留 →
- **03-33** 暗场不能只写「暗」：写唯一主光从哪来、什么颜色，阴影保留清楚的冷色相，明度分几组；特效光写成全画面最强最暖的光。〔实测〕 初判：留 →
- **03-26** 画风句按人物、道具、场景、关键帧分开写，每张再补本图特征，不全剧照抄同一句。〔自称已验证〕 初判：留 →
- **03-29** 写孩童不用大圆眼、圆脸，会把脸推成欧美 3D 卡通孩童，要写成国漫少年的脸。〔只测过一次〕 初判：留 →
- **03-25** 全身图要让脸在画面里大到看得清。〔只测过一次〕 初判：改写后留 →
- **03-47** 绑道具设定图时写「这是设定图，只画一件，不照搬版式」；画面里出现关键道具就绑它的设定图。〔实测〕 初判：留 →
- **03-46** 人物身份参考绑锁定的定妆照，不拿别的关键帧顶替，关键帧会把姿势和朝向带进来。〔只测过一次〕 初判：留 →
- **03-50** 同一地点换机位或反打：写「同一地点，只换机位」，写明相机站在哪一层，点名哪些地标和月亮这类光源在相机背后。〔实测〕 初判：留 →
- **03-58** 要读出来的字加引号逐字写，写清竖排几列、从哪列读起、只渲染一次；中远景里细长道具上的字读不出，要读就给近景。〔实测〕 初判：留 →
- **03-39** 全景、远景里脸只有十几像素，给每人写剪影、发式、服色、站位来认，不指望认脸。〔实测〕 初判：留 →
- **03-40** 群像的规模感靠纵深和前排大脸，不靠把人缩小；人群写朝向，前排、后排各写在做什么。〔实测〕 初判：留 →
- **03-41** 人物关系翻成这个机位看得见的样子：机位在哪、谁在前景、谁背对镜头、两人中间隔着什么。〔视频上实测〕 初判：留 →
- **03-43** 视线写看向谁，同时带画面方向；看的对象在画外就写在哪条画框边外；冲击来向和视线写同一侧。〔实测〕 初判：留 →
- **03-42** 过右肩拍前景的人在画左，过左肩在画右；写清相机在谁身后、前景是谁的后脑和肩、他面朝纵深里的对方。〔实测〕 初判：留 →
- **03-44** 手和有朝向的物件都用画面方向写：手伸向哪、从哪条画框边伸进来、左右手在画面哪侧；物件面朝哪、人在它哪边。〔实测〕 初判：留 →
- **03-45** 表情写眉、眼、嘴的具体形态，情绪落到这个景别看得出的视线、呼吸、姿态或手上，不只写情绪名。〔实测〕 初判：留 →
- **03-34** 光写从画面哪边来、照出什么结果（哪边亮、阴影留在哪、眼睛仍看得清），不只写「电影光」。〔只测过一次〕 初判：留 →
- **03-35** 场景的光由锁定的场景图管，正文只写这一镜光的变化和人物从哪边受光。〔无证据〕 初判：改写后留 →
- **03-36** 体积光按需要正面写（门缝一道光、光里有灰尘）：剧情镜头可以写，空景场景图不写。〔无证据〕 初判：改写，要你定 →
- **03-38** 三视图、道具图用正面平光、无投影、浅灰底；这种光只为看清形制，不当镜头的光。〔实测〕 初判：留 →
- **03-22** 详细是写看得见的事实，不堆「好看、史诗、高清、电影感、8K、杰作」；审美词要落到构图、材质、颜色或光上。〔无证据〕 初判：留 →
- **03-54** 交给 GPT Image 的提示词按官方的分段结构写，用中文标签：用途、主体、画风、构图、光、约束。〔外部文档〕 初判：改写后留 →
- **03-52** 参考图超过模型上限时，按起始帧、主动作的人、关键道具、地点、其余人的顺序保留；截掉的怎么补见待定 1。〔无证据〕 初判：改写后留 →
- **03-51** 站位用文字写就够，关键帧不另绑俯视站位图或平面图。〔实测〕 初判：留 →
- **03-59** 正文只写画面里看得见的东西，不放编号、文件路径、字段名、流程说明和符号标记。〔无证据〕 初判：留 →
- **03-56** 一件事在一条提示词里只说一次；改图时重述要保持的东西不算重复。〔外部文档〕 初判：改写后留 →
- **03-57** 静帧构图可以写：眼睛在上三分线、视线前方留空、前中后景分层、用门洞框住人、写明视觉重点在哪。〔无证据〕 初判：改写后留 →

## 建议删的（4 条）

- **03-30** 老李库的 3D 国漫全局画质声明（超写实材质、8K、HDR、胶片颗粒、拉丝眩光）。理由：Seedance 打戏视频的套话，超写实和摄影词正是把画面拉成照片的写法。 →
- **03-37** 中景发平时给人物加轮廓光。理由：没有实测、三处说法不一，「轮廓光」本身是摄影词，要分开人和背景用 03-03 那条的写法。 →
- **03-53** 正文末尾追加一段「参考 N 允许控制什么、不得控制什么」。理由：视频端测过去掉无差别，只绑图后由 03-10 的正文句承担。 →
- **03-55** 视频提示词 350 词下限、图片不设字数门槛。理由：350 词是 H3 英文视频的规则，图片长度按 03-21「写够」判，视频部分归 04 批。 →

## 已定或另议（不用再审，6 条）

- **03-02、03-15** 防照片感不列禁词、不写避免行，只靠用途、画风和光的正面描述写对。（你已定）
- **03-07** 「上个时代」的旧游戏 CG 脸、早期 AI 磨皮、塑料光泽不写进避免行，靠 03-08、03-09 的美型画风正面写对。（你已定）
- **03-16、03-17** 否定句只写此刻不该在画面里的具体东西（身后没有门、手里空着），不堆泛泛的负面词。（你已定）
- **03-24** 脸上油光靠写哑光、冷中性肤色避免，不写透亮、暖黄高光。（你已定，见 01-02）
- **03-04** 关键帧不再逐字照抄背景句、陈设锁、光锁，背景交给锁定场景图；陈设数量要不要补一句短词另议。（见待定 1）
- **03-05** 关键帧不抄服装全文；多人同框时人名后要不要加「穿白袍的」这类短区分词防串衣另议。（见待定 1）
